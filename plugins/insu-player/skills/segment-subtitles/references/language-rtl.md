# RTL segmentation profile

Preserve logical Unicode order in JSON and VTT. Let the browser apply bidirectional display; never reverse stored strings. Measure grapheme display units rather than shaped glyph count.

Protect clitics, attached articles or prepositions, construct-state phrases, names, numbers with units, and mixed-direction technical terms. Treat punctuation and spaces as candidates only after syntax review by the current Agent. Validate mixed RTL/LTR anchors by timed-unit IDs and target piece IDs, not visual screen positions.
